# ML Practice

This repository is my ongoing collection of machine learning practice work as I learn. Each folder covers a different topic, with a notebook, dataset, and notes explaining what I learned.

## 📁 Topics

| Folder | Topic | Description |
|---|---|---|
| [`linear-regression/`](./linear-regression) | Linear Regression | Practice predicting continuous values using linear regression. |
| [`logistic-regression/`](./logistic-regression) | Logistic Regression | Classification with logistic regression, including a comparison of model accuracy with and without `StandardScaler`. |
| [`knn/`](./knn) | K-Nearest Neighbors (KNN) | Classification using KNN, exploring the effect of different `k` values on accuracy. |
| [`kmeans/`](./kmeans) | K-Means Clustering | Unsupervised clustering practice, including using the elbow method to choose the number of clusters. |
| [`svm/`](./svm) | Support Vector Machine (SVM) | Classification with SVM, comparing different kernels (linear, rbf) and their effect on results. |

*(More topics will be added here as I practice — decision trees, random forest, etc.)*

## 🎯 Goal

I'm a fresher learning machine learning, and this repo is where I practice concepts hands-on rather than just reading about them — testing things out, comparing results, and writing down what I actually learned from each experiment.

## 🛠️ Tools Used

- Python
- pandas, numpy
- scikit-learn
- Jupyter Notebook

## 📌 How this repo is organized

Each topic folder contains:
- A Jupyter notebook (`.ipynb`) with the code
- The dataset used (`.csv`)
- A short `README.md` explaining the experiment and results
